## Mega Bench release

- Automatically discovers ordinary native crafting benches from enabled packs, with paid personal unlocks and original tier upgrades.
- Keeps original recipes and native craft, batch, cancellation and refund behavior; supports search, category tabs and batches of 1–16.
- Supports explicit physical-bench hand-in where no suitable bench recipe exists, plus server exclusions and identity overrides.
- Refreshes repository, player-guide and CurseForge artwork to the shared cinematic design language.

Requires Hytale >=0.7.4 <0.8.0 and Java 25; scoped native checks used 0.7.4. This Release channel is the selected distribution status, not a claim that every server/mod combination has been tested.

**Known limits:** processing, builder and special plugin stations need dedicated adapters. Actual second-client verification, human visual/listening review and broader survival/crash assurance remain open. Back up complete world/player data before updating. Older development access blocks may require ordinary breaking and replacement; unlock progress remains per player and world. Read the [compatibility guide](https://jkswoods.github.io/mega-bench/hytale0.7/compatibility/).

With the game/server stopped, install this release's JAR in UserData/Mods, remove older Mega Bench JARs, and enable MegaBench in the world's Mods settings. No custom launcher or separate resource ZIP is needed.
